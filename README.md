# Team Manager

Team Manager je projekt aplikacije za organizaciju timova i upravljanje zajedničkim zadacima. Cilj aplikacije je omogućiti pregled članova tima, raspodjelu odgovornosti i praćenje napretka na jednom mjestu.

## Namjena projekta

Aplikacija je zamišljena kao pomoć voditeljima i članovima timova u svakodnevnoj organizaciji rada. Trebala bi olakšati dogovor oko zadataka, jasno prikazati tko je za što odgovoran i pružiti uvid u tijek rada tima.

## Planirane funkcionalnosti

- Kreiranje timova i upravljanje njihovim članovima.
- Kreiranje zadataka i dodjela odgovornim članovima tima.
- Postavljanje rokova i praćenje statusa zadataka.
- Pregled aktivnosti i napretka tima.

## Status projekta

Projekt je u početnoj fazi. Repozitorij trenutačno sadrži opis projekta; izvorni kod aplikacije i upute za instalaciju i pokretanje bit će dodani tijekom razvoja.
